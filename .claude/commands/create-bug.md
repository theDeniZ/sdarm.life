# Create Bug Report

Reference template: [@.github/ISSUE_TEMPLATE/bug_report.yml](.github/ISSUE_TEMPLATE/bug_report.yml)

Create a new bug report issue on GitHub. Follow the template structure and gather the following information:

1. **Title** — Short, clear summary of the bug (e.g., "Song search crashes when query contains special characters")

2. **Description** — Clear description of what's broken (detailed explanation of the issue)

3. **Steps to reproduce** — Step-by-step instructions to reproduce the issue

4. **Expected behavior** — What should happen instead?

5. **Environment** — Browser, OS, device, and any relevant URLs
   - Browser: Chrome / Firefox / Safari / etc.
   - OS: macOS / Windows / Linux / iOS / Android
   - Device: Desktop / Mobile / Tablet
   - URL: https://...

6. **Screenshots** (optional) — Visual evidence if applicable

7. **Which app?** (optional) — Select from:
   - Web (sdarm.life)
   - Admin (admin.sdarm.life)
   - Songbook (songs.sdarm.life)
   - Treasures (treasures.sdarm.life)
   - Events (events.sdarm.life)
   - API (api.sdarm.life)
   - Other / Not sure

8. **Severity** (optional) — How much does this impact usage?
   - 🔴 Critical — breaks core functionality / causes data loss
   - 🟠 High — major feature doesn't work
   - 🟡 Medium — feature partially broken or workaround exists
   - 🟢 Low — cosmetic issue or minor inconvenience

After gathering this information, use the GitHub MCP tool to create the issue with:
- **Title** from step 1
- **Body** formatted with the gathered information
- **Label** `bug` (auto-applied)
- **Repository** `theDeniZ/sdarm.life`

Ensure all required fields are filled before creating the issue.
